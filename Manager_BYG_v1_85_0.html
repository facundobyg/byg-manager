☁️ Google Drive — Acceso compartido
SYNC MANUAL · COMPARTIBLE CON SOCIOS
El sistema guarda los datos en un archivo .json local. Para acceder desde múltiples dispositivos o compartir con socios, seguí estos pasos:
1️⃣
Guardá el archivo en Google Drive
Usá ↓ Backup JSON para descargar los datos, luego subilo a una carpeta de Drive que compartas con tus socios.
2️⃣
Abrí el sistema desde Drive
Guardá también el archivo BYG_Sistema_v50.html en Drive. Hacé doble clic → "Abrir con Google Chrome" para ejecutarlo directamente.
3️⃣
Al abrir: cargá los datos del día
Usá 📂 Abrir archivo para cargar el JSON de Drive. Al terminar, usá ↓ Backup JSON para guardarlo de vuelta en Drive con los cambios.
4️⃣
Socios: acceso de lectura
Compartí la carpeta de Drive en modo "Puede ver" para que Fran, Nanu o Daniel puedan descargar el JSON y el HTML y ver el sistema en modo lectura sin poder modificar los datos maestros.
📱 Flujo recomendado para uso móvil
1. En la PC: hacer Backup JSON → subir a Drive
2. En el celular: abrir el HTML desde Drive en Chrome → "Abrir archivo" → seleccionar el JSON de Drive
3. Consultá en tiempo real sin modificar datos
